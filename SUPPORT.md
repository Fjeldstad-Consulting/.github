# Support

## Who this is for

This file is the default for every repository in the Fjeldstad-Consulting organisation that has no support file of its own. Most of those repositories are private, and a few are public.

## People who work in the organisation

Work is coordinated through GitHub issues. Open an issue in the repository the question concerns, using one of the issue forms, and write it so that it can be understood without prior context and has criteria that show when it is done.

## Everyone else

The public repositories are published as they are. There is no support for them, issues from outside the organisation may be closed without a reply, and pull requests are not accepted.

If you want to talk about advisory work, use the contact form on the company website: <https://fjeldstadconsulting.ai/#kontakt>.

## Security problems

Do not open an issue. Follow the [security policy](https://github.com/Fjeldstad-Consulting/.github/blob/main/SECURITY.md).
