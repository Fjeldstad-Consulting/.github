# AGENTS.md

Instructions for any AI agent working in or from this repository. This file is the canonical source. Tool-specific files (such as `CLAUDE.md`) only point here.

## What this repository is

The shared working rig for Fjeldstad Consulting: how the work is done, written and checked. It is model-agnostic and must stay usable by any agent that can read a GitHub repository.

This repository is the top of the hierarchy for all Fjeldstad Consulting work. Its rules apply in every other FC repository, and lower levels may tighten them but never loosen them. See `docs/hierarchy.md`.

## Hard rules

1. Follow `docs/classification.md` for everything you add. No client data, business figures or local values.
2. Never commit secrets, keys or tokens. Never ask for them and never print them.
3. Personal and machine-specific values come from local config (`local-config.example.md` lists the keys). If a value is missing, say so and continue without it.
4. Coordinate work through GitHub issues, not files in the repository. Every issue follows `docs/issue-guidelines.md`: understandable without prior context, with verifiable Done when criteria.
5. Write in British English in this repository. Reply to people in the language they use.
6. Never merge a pull request that changes the secret scan (`.github/workflows/`, `.githooks/pre-commit`, `.gitleaks.toml`, `.gitleaksignore`). If you open one, say so in its description on a line starting with `Secret scan change:` and leave the merge to the owner. See `docs/hierarchy.md`, Break glass.

## Writing skills and assistants

Before creating or changing anything under `skills/` or `assistants/`, read `docs/skill-authoring.md`. For assistants, also read `docs/assistant-authoring.md`. Start new work from `docs/templates/`; the shared company profile template is `shared/company-profile.template.md`. Run the checklist at the end of the relevant guide before marking anything approved.

## Skills

Each skill is a folder under `skills/` with a `SKILL.md`. Read the `SKILL.md` when a task matches its description, then follow it.

- `skills/writing/`: write, polish, coach and review text in Norwegian or English in the author's own voice. The owner's house style for it is `config/writing/house-style.md`.

Skills are installed under a name prefix chosen in the company profile. This repository uses `fc-`, so `skills/writing/` is installed as `fc-writing`. The installed Claude Code copies in `.claude/skills/` are generated by `python scripts/build.py`; never edit them by hand.
